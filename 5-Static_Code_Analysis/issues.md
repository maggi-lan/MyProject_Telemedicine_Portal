# Issues and Fixes

| Issue                                          | Type                 | Original line(s) | Description                                                                        | Fix approach                                                                                                                    |
| ---------------------------------------------- | -------------------- | ---------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Unsafe eval()                                  | Security             | 12               | User-provided formula was executed as Python code.                                 | Replaced eval with an AST-based evaluator that permits only numeric constants, gpa/credits variables, and arithmetic operators. |
| Bare except with pass                          | Reliability/Security | 35-38            | All exceptions were silently swallowed, hiding corrupt files and unrelated errors. | Handle missing files separately; raise a clear ValueError for malformed or unreadable JSON.                                     |
| Mutable default logs=[]                        | Bug                  | 14               | The same list could be shared across calls.                                        | Use logs=None and create a fresh list inside the function.                                                                      |
| Unclosed/unmanaged file handles                | Reliability          | 28-30, 36        | Files were opened without context managers or explicit encoding.                   | Use pathlib.Path.open with with-statements and UTF-8 encoding.                                                                  |
| Global state                                   | Maintainability      | 6, 25, 34        | Functions changed module-level results/formula state.                              | Pass results and formula explicitly; load_results returns the loaded dictionary.                                                |
| Unused imports                                 | Style                | 2-3              | math and sys were imported but unused.                                             | Removed unused imports.                                                                                                         |
| Non-PEP 8 function name and boolean comparison | Style                | 40, 43           | printShortlist violated snake_case; == True was unnecessary.                       | Renamed to print_shortlist and used an explicit True identity check.                                                            |
| Missing docstrings and spacing                 | Style                | multiple         | Module/functions lacked docstrings and blank-line spacing.                         | Added docstrings and formatted functions consistently.                                                                          |
| Percent string formatting                      | Style                | 21               | Old-style formatting triggered a lint warning.                                     | Changed to an f-string.                                                                                                         |
